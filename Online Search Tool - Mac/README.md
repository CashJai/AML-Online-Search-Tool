# Online Search Tool V2 (Mac)

This tool automates adverse news and generic searches on Bing and produces comprehensive PDF and Excel reports.

## Prerequisites

To run this tool, you must have **Node.js** installed on your system.

### How to install Node.js:
1. Go to the official Node.js website: https://nodejs.org/
2. Download and install the **LTS (Long Term Support)** version for macOS.
3. Once installed, you can proceed to run the tool.

## How to Run
1. Open the folder containing the tool.
2. Double-click the `Run Search.command` file.
   - *Note: On the first run, macOS might block it since it is an unverified script. If this happens, right-click `Run Search.command` and select **Open**.*
3. On the very first run, it will automatically download necessary dependencies and a local browser (Chromium). This might take a few minutes.
4. Follow the on-screen instructions to enter subject names and start the search.

All search results will be saved into the `Search Results` folder.
